## Assistant

Oui, c’est fréquent : beaucoup de clims sont sur le Wi‑Fi « IoT », un guest, ou uniquement via le cloud constructeur.

Conséquences :

- **Même LAN / VLAN routable** → intégration locale possible (API, Matter, HomeKit…).
- **Réseau isolé / pas de route vers HA** → pas d’accès local ; il reste le **cloud** (si l’intégration HA le gère) ou rien.

Même hors LAN, si l’app téléphone marche, le cloud constructeur est souvent joignable depuis HA (autre chemin Internet).

Marque / app utilisée ? Ça tranche vite entre cloud, local, ou détection conso.
