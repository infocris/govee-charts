## Assistant

Oui, **en principe** — mais pas vraiment sous la forme « j’inscris mon webservice et Chrome parle tout seul sans rien d’ouvert », clé en main.

## Ce que Chrome permet vraiment

Une **extension** peut parler **sans onglet visible** via l’API `chrome.tts` (moteur TTS de Chrome / du système), depuis le **service worker** de l’extension.

Limites Manifest V3 :
- le service worker **s’endort** s’il ne se passe rien ;
- il faut le **réveiller** (alarme, message, push, événement réseau…) ;
- ce n’est **pas** le même moteur que `speechSynthesis` d’une page web (donc pas les mêmes voix / edge-tts côté page).

## Extension « j’enregistre mon webservice » ?

Je ne connais **pas** d’extension grand public du type :
> « enregistre l’URL de mon API / webhook, et dès qu’elle appelle, Chrome fait du TTS sans fenêtre »

Les extensions TTS courantes (lecteurs de page, Read Aloud, etc.) parlent surtout **dans le contexte d’un onglet** ou au clic.

## Ce qui marche en pratique

| Approche | Fenêtre ouverte ? | Commentaire |
|----------|-------------------|-------------|
| Extension custom + `chrome.tts` | Non (idéalement) | À coder ; réveil du SW à gérer |
| Extension + **native messaging** vers un petit daemon | Non | Le plus fiable pour du TTS « toujours on » |
| Serveur local **edge-tts** + script/systemd | Non | Ce que tu as déjà côté lab / govee-charts |
| Pousser une **notification** | Non | Texte affiché, TTS navigateur très limité / pas fiable en arrière-plan |
| Garder un **onglet** govee-charts | Oui | Ce que tu évites |

## Conclusion

- **Oui**, techniquement une extension peut faire du TTS sans onglet (`chrome.tts`).
- **Non**, il n’y a pas (à ma connaissance) d’extension prête à l’emploi pour « brancher n’importe quel webservice » comme un broker TTS.
- Pour govee-charts / alertes maison, le chemin réaliste c’est plutôt : **petit agent local** (extension dédiée ou daemon) qui écoute tes alertes et parle, pas un simple webservice HTTP ouvert dans Chrome.

Si tu veux, on peut esquisser une mini-extension « reçoit un POST local → `chrome.tts.speak` » branchée sur tes alertes govee-charts.
